# GTU PPS practice programs in C

Eight beginner C programs for GTU first-year Programming for Problem Solving (PPS). PPS appears under codes such as 3110003 and BE01000121 in different B.E. listings, so match your own code before using old papers.

This is a practice list, not a prediction of what will come in the exam. Compile any file with `gcc file.c -o out && ./out`.

Full guide with past paper links and a study plan: [GTU Hero PPS previous year paper guide](https://gtuhero.com/blogs/gtu-pps-previous-year-paper).

Disclosure: GTU Hero is my project.

## Files

| File | Concept |
|---|---|
| 1_even_odd.c | if-else, % operator |
| 2_factorial.c | loops and recursion |
| 3_prime.c | loops, flags, edge cases (1 is not prime) |
| 4_fibonacci.c | updating two variables |
| 5_sum_of_digits.c | % 10 and / 10 |
| 6_palindrome.c | reversing a number |
| 7_largest_of_three.c | comparisons with equal inputs |
| 8_armstrong.c | digit extraction and powers |
